The whole ritual

        
    
          
  1. 
            mm add "CS302"
            
    Put work in the box when you want it there.
    
          
    2. 
          
  2. 
            mm
            
    See the one thing to do. An interrupt sits on top until you finish it.
    
          
    3. 
          
  3. 
            mm done
            
    Mark it finished. The next thing you added is what’s left.

Install

        
Python 3.11 or newer. Nothing to pip install.

        

          
git clone https://github.com/Toseef-Ahmad/mm.git
cd mm && ./install.sh

          
        

        
That writes ~/bin/mm and the manual, man mm. Your list is one file, ~/.mm/state.json. If an older mm left toml or habit files behind, delete ~/.mm and start empty.


        
Commands

        

          
            
CommandWhat it does

          
          
            
mm · mm next · mm peekWhat to do. Peek does not start the timer.

            
mm add "task" · -p · -qQueue, interrupt, or quick.

            
mm doneFinish the current item and show the next one.

            
mm block · mm unblockStuck. Requeue it and move on.

            
mm suspend · mm resumePark an item, or bring it back.

            
mm move · mm rm · mm editReclassify, remove, or rewrite.

            
mm note · mm findAnnotate, then search.

            
mm undoReverse the last change.

            
mm status · mm statsSee the box, or today’s counts.

            
mm flush-quickClear the quick tray at a checkpoint.

            
mm archive · mm export · mm logWhat you finished, a dump, the event log.
